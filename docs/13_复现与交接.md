# 复现与交接

> 本文给"拿到仓库的人"一条最短路径：环境 → 一键复现 → 验证 → 交付物 → 企业赛适配。
> 全部命令在 macOS（arm64）+ bundled Python 3.12 上实测通过；纯 CPU、运行期零网络。

---

## 1. 环境

| 项 | 要求 | 说明 |
|---|---|---|
| Python | ≥3.10（实测 3.12） | 系统本体只依赖 **numpy**（≥1.24） |
| 依赖 | `numpy` | `requirements.txt`；`openpyxl`（记录汇编 xlsx）与 `swanlab`（上云记录）为可选软依赖 |
| 算力 | 普通 CPU（无需 GPU） | 全量实验矩阵约 10–15 分钟；基线套件约 2.5 分钟 |
| 网络 | **运行期不需要** | 仅准备阶段可下载 AI4I 公开数据（已随仓库提供 zip 与离线解压） |

本机 bundled Python（DSH 环境）：

```bash
PY=python3
```

> 图表脚本需要 matplotlib（系统本体不需要）。因为 macOS 代码签名限制，matplotlib 装在
> 独立 venv（系统 Python 3.9）：`/usr/bin/python3 -m venv /tmp/plotenv && /tmp/plotenv/bin/pip install matplotlib`。
> 若 venv 路径不同：`FIGPY=/path/to/python bash scripts/build_all.sh`。

## 3. 分步命令（调试/评分环境用）

```bash
PY=.../python3

# 一次完整闭环（无人干预；等价于封闭评测入口）
$PY -m src.cli run --config configs/main.json --group main --seed 7

# 快速验证
$PY -m src.cli run --config configs/quick.json --seed 7

# 审计链校验（哈希链完整性）
$PY -m src.cli audit-verify --path experiments/audit

# 复现校验（用记录里的配置重跑，逐窗口比较）
$PY -m src.cli repro --result results/main/synth_S7_full_mix_seed7.json

# 实验记录查询 / 两次 run 对比 / 导出
$PY scripts/query_records.py stats
$PY scripts/query_records.py list --group main --kind deploy
$PY scripts/query_records.py compare <run_id_a> <run_id_b>
$PY scripts/query_records.py export --fmt csv --out results/records_main.csv --group main
```

## 5. 复现性保证

1. 所有随机性显式 seed（benchmark / model / planner / rng）；
2. 每次 run 保存 `config_used.json` 与 `result.json`，含完整配置与时间线；
3. `python -m src.cli repro` 用记录中的配置重跑，断言逐窗口曲线一致（acceptance A7）；
4. 审计链：`Decision` → `RunRecord` → 代码路径，全部可追溯；
5. 固定"物理世界"（`WORLD_SEED`），seed 只改变采样与初始化 → 跨 seed 难度方差 ≤±0.03。

## 6. 企业赛/官方评测环境适配

1. 拿到官方数据包后按 `docs/15` 放置到 `data/official/`，`configs/official_template.json` 改路径；
2. 先跑数据校验：`$PY -m src.data.adapter --validate data/official`（或 adapter 的 validate 函数）；
3. `python -m src.cli run --config configs/official_template.json` 跑通一次闭环；
4. 用 `results/` 与静态基线确认"隐藏流上不退化"，再提交系统镜像（`zhixun_engine_system.zip`）；
5. 若企业赛提供 PyTRi0 额度：设置环境变量
   `ZHIXUN_LLM_BASE_URL / ZHIXUN_LLM_API_KEY / ZHIXUN_LLM_MODEL`（OpenAI 兼容），
   `configs/main.json` 设 `harness.driver=llm`，即可用 Qwen3.8-27B 驱动 Harness（token 自动记账）。

**评测机约束对照**：Python≥3.10 ✓；纯 CPU ✓；离线 ✓；无 GUI ✓；单命令输出结果 ✓；
全部实验记录本地落盘 ✓；不访问外部网络 ✓；kill-switch（`STOP` 文件）✓。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: matplotlib` | 图脚本不在系统依赖内 | 用独立 venv（`FIGPY`）跑 `make_figures.py` |
| SwanLab 未安装 | 软依赖 | 自动降级本地镜像并写 `tracker_warnings.jsonl`；需上云时 `pip install swanlab` |
| 构建 PPT 报"缺少 SUMMARY.json" | 未跑主实验 | 先 `python scripts/run_all.py ...`（禁止用假数字出正式材料） |
| 运行中途停止更新 | 存在 `STOP` 文件 / 预算耗尽 / 连续失败达上限 | 属预期熔断；删除 STOP 或调大预算后重跑 |
| 结果与 docs 数字不一致 | 改了引擎/配置后未重跑矩阵 | 重跑 `build_all.sh`，docs/10 的表格由 `results/SUMMARY.json` 回填 |
| 想复现某个历史 run | —— | `python -m src.cli repro --result results/<group>/<file>.json` |
