## 1. 我们做了什么

一个**工业模型自进化系统**：在无标签、分布持续漂移的部署流上，自动完成

```
漂移监测 → 诊断归因 → 实验优化 → 评估上线 → 回滚
    └──────────── 策略层自改进（bandit 策略表）────────────┘
```

并满足三个硬约束：**预算受限**（算力/标注/Token 全记账）、**无人干预**（一条命令跑完）、
**安全可控**（白名单/预算硬门/高风险升级/kill-switch/哈希链审计/随时回滚）。

## 2. 三个核心判断

### 判断一：漂移分类型，动作分阶梯 —— 不是所有漂移都值得重训
轴承磨损要微调、传感器老化**零标签**就能校准、工况切换要带标签微调、新故障要扩类别、
维修复位要能回滚。我们把 9 个动作做成"成本阶梯"（0 标签 → 少量标签 → 重训 → 类别扩展 → 回滚），
让诊断结果决定花多少钱。**NOOP 是合法动作**——在单位增益成本口径下，错误更新比不更新更糟。

### 判断二：LLM 不能进高频回路，但必须是 Harness 的一部分
每窗口的数值决策（是否触发、选哪个动作、预算多少）用确定性策略 + 在线 bandit，
零 token、可复现；LLM 只出现在"每漂移一次"的归因解释与实验设计，以及报告生成。
Harness 仍然完整（12 个工具 + 7 个技能 + 确定性/LLM 双驱动），只是默认驱动不烧 token。
按 PyTRi0 公开定价估算，这个取舍把 LLM 成本压到每 run < ¥0.3（详见 docs/02 §3.3）。

### 判断三：受控 RSI = 可审计的数值策略层 + 不可变模型版本
"递归自改进"只允许发生在两处：模型层（版本仓库滚动）和策略层（bandit 先验更新）。
策略层只能改先验数值，不能改代码/门禁/预算；模型版本不可变、lineage 完整、可回滚；
所有决策写入 sha256 哈希链审计日志。**自我改进有边界，且边界可验证。**

## 3. 系统一览

| 层 | 组件 | 关键设计 |
|---|---|---|
| 数据 | 合成漂移基准（7 场景）+ 公开工业数据 + 官方数据适配器 | 隐藏测试标签物理隔离；标注只能按预算经 oracle 获取 |
| 监测 | MMD / 逐特征 KS / 熵-边际代理 / Page-Hinkley / novelty / 探针准确率 | 三层漏斗第一层：零标签、低成本 |
| 诊断 | 8 类漂移归因 + 仿射可恢复性实测 + 类别先验估计 | 三层漏斗第二层：少量探针标签，输出推荐先验 |
| 优化 | 9 个 playbook + bandit 规划器 + 预算硬约束 | 三层漏斗第三层：才花大预算；cheapest-first |
| 上线 | 门禁（增益/类召回/校准/成本/可复现）+ registry + watchdog | 不达标不上线；上线后持续监控自动回滚 |
| 记录 | 本地 SQLite 镜像 + SwanLab 兼容（online/local/offline） | 每次触发/实验/上线/回滚都是一个可查询 run |
| 安全 | 白名单 / 预算硬门 / kill-switch / 高风险升级 / 哈希链审计 | 负向测试覆盖（越权、超预算、异常降级） |
| Harness | 12 个工具 + 7 个技能 + 确定性/LLM 双驱动 | LLM 可插拔（PyTRi0 Qwen3.8-27B 兼容） |

## 5. 快速开始

```bash
PY=python3
$PY scripts/smoke.py                              # 3 秒冒烟
$PY -m unittest discover -s tests -v              # 全部测试
$PY -m src.cli run --config configs/main.json     # 跑一次完整闭环（无人干预）
$PY -m src.cli suite --groups main --seeds 7,17,27  # 跑主实验
$PY scripts/run_all.py --groups main,scenarios,ablations,budget,real --seeds 7,17,27
```

## 6. 边界与诚实声明

1. 校赛阶段**没有官方数据包**：主实验在可控合成漂移基准 + 公开工业数据上完成；
   隐藏测试流与标注预算约束在仿真中真实生效（不是用测试集调参）。
2. **没有 PyTRi0 额度**：LLM 驱动路径完整实现但默认不启用；企业赛一条配置切换，
   论文级对比留给有额度的阶段。
3. 合成基准不能完全代表真实工业分布：我们给出了与官方数据对接的接口（docs/15）与
   风险清单（docs/09 §5），并保留"拿到数据后 1 天内完成接入验证"的路径。
