# 系统架构、接口契约与目录结构（FROZEN v1.0）

> 本文件是并行开发的**唯一协作契约**。所有人的代码必须实现本文件声明的接口；
> 如需变更契约，必须先通知 Lead 并更新本文件（版本号 +1）。
> 数据结构定义以 `src/core/spec.py` 为准，配置默认值以 `src/core/config.py` 为准。

## 0. 一句话架构

```
                         ┌──────────────────────────── 策略层（自改进）────────────────────────────┐
                         │  Planner(Bandit/预算调度) → 策略表持久化 → 下轮先验更新（受控 RSI）        │
                         └──────────────────────────────────────────────────────────────────────────┘
 部署流 chunk(t) ──▶ Monitor ──触发──▶ Diagnose ──▶ Optimize(Playbooks+预算) ──▶ Gate ──▶ Registry
   （无标签 x）        │ 统计检验          │ 归因        │ 候选实验（小预算）        │ 上线门禁    │ champion
                      │ 代理指标          │ 类型/范围   │                          │            │ /rollback
                      ▼                  ▼             ▼                          ▼            ▼
                 RunRecord/指标  ──────────▶ Tracker（本地 SQLite+JSONL 镜像，SwanLab 兼容/可上云）
                      │
                      └──▶ Harness（Tools+Skills，可选 LLM 驱动；默认确定性策略）─→ 全部决策可审计
 平台侧：HiddenEvaluator 只读隐藏测试标签，评估 champion 但不向系统泄露标签；LabelOracle 按预算供标签。
```

两层自进化：
- **模型层**：champion 模型版本在 Registry 中滚动更新（候选→门禁→上线→回滚）；
- **策略层**：`Planner` 把"诊断类型 → playbook → 实际增益/成本"写回策略表，下一轮先验更新；
  但受硬预算、动作白名单、风险门禁约束（受控递归自改进，非无限制自我修改）。

**硬规则**
1. 不得修改他人写作用域内的文件；需要 core 变更时给 Lead 发消息。
2. 系统代码只依赖 **numpy**（`src/**` 内不得 import torch/sklearn/matplotlib/scipy；SwanLab 用 try/except 软依赖）。
3. 系统运行期**禁止网络访问**（安全要求）；SwanLab 仅在显式配置 `tracker.backend=swanlab` 时联网。
4. 所有随机性使用显式 seed；同一配置必须可复现（`tests` 中验证两次运行结果一致）。
5. 每个模块必须有 `unittest` 测试，并且写完跑通 `scripts/smoke.py` 与自己的测试。

## 3. 模型层契约（`src/core/model.py`，已实现）

```python
class MLP:
    def __init__(d_in, n_classes, hidden=(64,32), seed=0, scaler=None, l2=1e-4)
    def fit(x, y, epochs, lr, batch, class_weights=None, seed=0,
            refit_scaler=True) -> TrainResult   # TrainResult.sample_updates 用于成本核算
    def fit_head(x, y, epochs, lr, batch, seed=0) -> TrainResult   # 仅最后一层
    def predict_proba(x); def predict(x)
    def state() / from_state(state) / save(path) / load(path); def clone()
    def estimate_target_scaler(x) -> ScalerState
    def align_predict_proba(x, target_scaler) -> proba   # 无标签仿射校准
def expand_model_classes(model, n_classes_new, seed=0) -> MLP
def class_weights_from_labels(y, n_classes)
```

**算力单位**：`Cost.compute_units = sample_updates / cfg.cost_model.base_compute_unit`。
base 训练本身不计入"适应成本"（各方法都同样付出）；计入的是部署后的所有更新。

## 4. 引擎层契约（`src/engine/`，B 实现）

### 4.1 监测 `monitor.py`
```python
class DriftMonitor:
    def __init__(self, cfg, n_features, n_classes)
    def reset_reference(self, x_ref: np.ndarray)          # 初始参考窗口
    def update(self, chunk: StreamChunk, model, oracle) -> MonitorReport
class MonitorReport:  # dataclass
    events: list[DriftEvent]
    state: dict       # 供记录: mmd, ks_topk, proxy_entropy, proxy_margin, ph_stat, probe_acc...
```
监测至少包含：
- 无标签：MMD(RBF) 对参考窗口、逐特征 KS top-k、预测熵/边际分布漂移、Page-Hinkley 代理指标突变；
- 少量标注：每 `probe_every` 窗口用 `oracle` 取 `probe_labels` 条做准确率探针（预算内，且必须记录成本）；
- 参考窗口机制：初始 warmup 窗口为参考；漂移后参考窗口更新策略由 B 设计并记录在 docs/04。

### 4.2 诊断归因 `diagnosis.py`
```python
class Diagnoser:
    def __init__(self, cfg, n_features, n_classes, feature_groups: dict[int, str])
    def diagnose(self, chunk, model, report: MonitorReport, history,
                 oracle) -> Diagnosis
```
输出 `Diagnosis.kind ∈ {benign, covariate_affine, condition_switch, concept, novel_class, label_shift, noise_inflate, repair}`，
并给出 `affected_features/affected_groups/affected_classes/prior_delta_estimate/recommended`。
`recommended` 为 `[{"playbook": name, "prior": 0-1, "why": str}]`，按先验降序。

### 4.3 Playbook 动作库 `playbooks.py`
```python
class PlaybookLibrary:
    def __init__(self, cfg, oracle, cost_model)
    def specs(self) -> list[PlaybookSpec]
    def estimate_cost(self, name: str, diagnosis: Diagnosis, chunk, budget) -> Cost
    def run(self, name: str, ctx: PlaybookContext) -> ExperimentResult
@dataclass
class PlaybookContext:
    model: MLP; chunk: StreamChunk; base_x; base_y; config; n_classes
    history: list; diagnosis: Diagnosis; budget: BudgetState; rng
@dataclass
class ExperimentResult:
    model: MLP; metrics: dict; cost: Cost; artifacts: list; params: dict; note: str
```
必须实现的 playbook（名字与 `cfg.safety.allowed_playbooks` 一致）：
| name | 层 | 说明 | 标签 | 风险 |
|---|---|---|---|---|
| `NOOP` | model | 不更新，仅记录 | 0 | low |
| `RECALIBRATE_AFFINE` | model | 无标签目标域统计量仿射校准（`align_predict_proba`） | 0 | low |
| `PRIOR_CORRECTION` | model | EM/BBSE 估计类别先验并重加权 | 0 | low |
| `LAST_LAYER_FT` | model | 冻结隐藏层，只用少量标签训练最后一层 | 少 | low |
| `FULL_FINETUNE_REPLAY` | model | 全量微调 + 回放缓冲（历史数据），标签预算内 | 中 | medium |
| `RETRAIN_MIXED` | model | 从零在"回放+新标注"混合集重训 | 多 | medium |
| `NOVEL_CLASS_EXTEND` | model | 检测新类→扩展输出层→带标签训练 | 多 | high |
| `SHADOW_ONLY` | strategy | 候选模型仅做影子评估，不替换 champion | 0 | low |
| `ROLLBACK` | strategy | champion 回退到上一稳定版本 | 0 | medium |

每个 playbook 的 `metrics` 至少含：`probe_macro_f1`（用 oracle 探针或留出标注子集）、
`pred_stability`（与 champion 在无标签窗口上的一致率）、`class_recall_min`、`cost`。

### 4.4 规划器 `planner.py`
```python
class Planner:
    def __init__(self, cfg, budget, library, policy_path)
    def propose(self, diagnosis, chunk, state) -> list[Candidate]   # 受预算/白名单约束
    def order(self, candidates) -> list[Candidate]                  # cheapest-first + 先验
    def update_strategy(self, diagnosis_kind, playbook, reward: float, cost: Cost) -> None
    # 策略表持久化到 experiments/strategy_policy.json（策略层自改进的可审计状态）
```
`Candidate = {"playbook": str, "est_cost": Cost, "prior": float, "why": str}`。
规划器必须实现 bandit（默认 Thompson/UCD 简化版）+ 预算硬约束 + 最多 `cfg.planner.max_candidates` 个候选。
策略表默认按 run 隔离（`experiments/runs/<run_id>/strategy_policy.json`，`engine.planner.policy_scope="run"`），
保证评测可复现；置 `"global"` 时跨 run 累积经验。

### 4.5 门禁 `gates.py`
```python
class Gate:
    def __init__(self, cfg)
    def evaluate(self, candidate: dict, incumbent: dict, ctx: dict) -> GateResult
```
判定项（至少）：相对 champion 的 probe 增益 ≥ `min_gain_points`；最低类召回不塌陷（`max_recall_drop`）；
校准不显著恶化；成本 ≤ `max_cost_per_update`；候选必须可加载/可复现；
高风险 playbook 需 `human_gate`（默认在校赛阶段以 `escalation` 记录代替人工，见 docs/06）。

### 4.6 模型仓库 `registry.py`
```python
class ModelRegistry:
    def __init__(self, run_dir: Path, artifacts_dir: Path, n_features, n_classes, cfg)
    def add(self, model: MLP, meta: dict) -> ModelVersion      # 保存 npz + 元数据
    def champion(self) -> tuple[ModelVersion, MLP]
    def get(self, version: int) -> tuple[ModelVersion, MLP]
    def promote(self, version: int) -> ModelVersion
    def rollback(self, to_version: int, reason: str) -> ModelVersion
    def history(self) -> list[ModelVersion]
```
要求：版本不可变、lineage 完整、artifact 路径记录在 `ModelVersion.artifact`，
每次 promote/rollback 写 RunRecord（由 loop 负责，registry 提供事件）。

### 4.7 安全护栏 `safety.py`
```python
class SafetyGuard:
    def __init__(self, cfg, budget)
    def check(self, action: str, payload: dict, state: dict) -> tuple[bool, dict]
    # 返回 (allowed, checks) —— checks 用于写入 Decision.safety
    def should_kill(self) -> bool        # 读取 cfg.safety.kill_switch_file
class AuditLog:
    def __init__(self, path: Path)
    def append(self, record: dict) -> dict   # {"seq", "prev_hash", "hash", "record"}
    def verify(self) -> bool                  # 哈希链完整性自检
```
护栏至少：动作白名单、预算硬约束、单窗口更新次数、连续失败上限、token/决策上限、
kill-switch 文件、越权/网络访问禁止、高风险动作升级记录。
审计日志为 **sha256 哈希链**：`hash = sha256(prev_hash + canonical_json(record))`。

### 4.8 上线看门狗 `watchdog.py`
```python
class Watchdog:
    def __init__(self, cfg)
    def observe(self, t: int, phase: int, score: float, champion_version: int) -> dict
    # {"action": "none"|"rollback"|"recover", "reason": str, "drop": float}
    def reset(self)
```
上线后连续 `rollback_window` 个窗口相对参考性能下降超过 `rollback_drop_points` → 触发回滚。

## 8. 验收口径（对齐评分）

1. **无人干预**：`python -m src.cli run` 一条命令跑完，无交互、无网络、无 GUI；
2. **不低于静态基线**：主场景 S7 的流式 macro-F1 面积 ≥ 静态基线；
3. **可审计**：每个决策都能从 `Decision` → `RunRecord`/SwanLab run → 代码+配置+seed 追溯；
4. **成本可量化**：compute_units / labels / tokens 三项逐窗口累计，输出成本-增益表；
5. **安全受控**：动作白名单、预算硬门、kill-switch、回滚演练全部有测试覆盖。
