## 0. 一页纸结论（TL;DR）

1. **"自进化"已从设想变成公司级工程议程（2026）**：Anthropic《When AI builds itself》（2026-06）称内部 >80% 合并代码由 Claude 写、METR 外评研发加速约 2×，AAR 自动对齐研究在 10 类任务上超过 28 名人类；OpenAI Tax AI 工程博客（2026-05）用"专家反馈+生产轨迹+定制 evals+Codex 迭代"把字段准确率 6 周从 25% 提到 86%；Google AlphaEvolve（arXiv:2506.13131）已 GA 并在 Klarna 生产环境三周探索近 6000 个候选程序。→ **方向合法性无需自证，但也意味着概念已被占位。**
2. **"门禁式受控自进化"在 2026 年集中爆发，与我们的卖点正面撞车**：VaG（arXiv:2608.05810）论证技能污染不可逆、**预提交门禁优于事后回滚**；Bilevel Autoresearch（arXiv:2603.23420）已做机制级双层 RSI 并指出需要门禁/版本/回滚；Gated 自进化动力学（arXiv:2610.03243）给出"评估器必须留在被评估种群之外"的分离定理；Self-Improvement Problem（arXiv:2610.21646）证明通用自改门禁不可兼得可靠与非保守，但**有界评估+有限提案预算**可恢复保证。→ **不能声称"首次提出门禁/回滚"，创新必须落在"无标签工业漂移流 + 预算内探针标签构造临时验证器 + 双门不变量"。**
3. **TTA 的"适应即收益"假设已被文献打破**：无泄漏 harness 下 TTA 增益被高估（arXiv:2610.12232，标签延迟下可虚增 110%）；CTTA 综述（TMLR 2026，arXiv:2607.08164）指出遗忘与伪标签误差累积是两大失败模式。→ 直接支撑我们"先小样本探针实测增益、过门禁才更新、NOOP 合法"的设计。
4. **Agent Harness 已成工程学科**：Anthropic 的 MCP→Claude Code→Skills→harness 三原则（评估器必须独立、假设会过期、技能=文本+bash）与 OpenAI 的 AgentKit Evals/改进飞轮/Harness engineering 均已成体系。→ 我们的 12 工具+7 技能+确定性/LLM 双驱动与主流同构；差异必须在**工业闭环与预算治理**，而不是"有 Harness"本身。
5. **工业侧存在真实且明确的缺口**：华为盘古预测大模型在万华化学 2000+ 设备把预测准确率从 70% 提到 90%（全昇腾训练的盘古 5.5/Ultra MoE 718B），软通天璇 MaaS/AI Factory/数智本体平台覆盖"模型接入—微调—部署—行业本体"，Token 工厂开源 LoadGen 2.0 性能基准；但两家公开材料都描述"生产过程控制闭环"，**没有描述"模型质量自身的闭环"（自动发现失准→自主实验→门禁上线→失败回滚）**。→ 这是我们最自然的产业落点；但所有"填补空白/国内首次"表述必须改写为"在既有基座与平台之上补齐自动决策—门禁—回滚控制回路"。
6. **安全治理已高度成型，"机制而非承诺"是关键**：Google FSF v3（2025-09-22，2026-04 更新）含 CCL 与关停基础设施；OpenAI Preparedness Framework v2（2025-04-15）把 **AI Self-improvement 列为 Tracked Category**，Path to Astra（2026-09-01）首次判定 Critical 网络能力并推迟发布；Anthropic RSP v3.0（2026-02-24）/v3.4（2026-07-08）出现"承诺退坡"争议。→ 我们的"白名单/预算硬门/探针门禁/回滚/哈希链审计/kill-switch"应被表述为**代码化硬机制**，这正是相对政策承诺的优势。
7. **参数级持续学习仍是研究前沿**：Google Nested Learning（NeurIPS 2025，arXiv:2512.24695）、Titans/MIRAS（arXiv:2501.00663，官方 blog 2025-12）尝试测试时记忆与多时间尺度优化，但灾难性遗忘与稳定性未解。→ 我们明确**不碰参数级自改**，只做"模型版本滚动 + 策略层数值先验"，这是刻意的边界而非能力不足。
8. **实验记录与可观测成为平台竞争点**：SwanLab 2026 推出重构 SDK v0.8、CLI 与 Skill（面向 AutoResearch）、baseline 对比与昇腾/ROCm 支持；AgentOps 综述（arXiv:2508.02121）、TRAIL（arXiv:2505.08638）、OpenTelemetry GenAI spans 生态兴起。→ 我们"SQLite 本地镜像 + SwanLab 兼容 + run_id/哈希链审计"的设计与此同向。
9. **模型层"版本滚动"有产业先例**：DeepSeek 2024-12 V3 → 2025-01 R1 → 2025-09 V3.2-Exp → 2025-12 V3.2 → 2026-04 V4（1M 上下文）→ 2026-09 V4.1-Flash，平均 5–10 周一个版本；R1 登上 Nature（645:633–638, 2025）、SPCT（arXiv:2504.02495）证明"自我验证"可在**有验证器**的可验证域成立。→ 我们的 playbook 版本滚动是其"应用层、无验证器"对应物。
10. **新颖性结论（写法已按文献校准）**：我们的贡献应表述为 **组合创新 + 治理/评测协议 + 可复现工程证据**，具体为 N1 双层受控 RSI 的预算硬门/探针门禁/回滚/审计闭环、N2 无标签漂移流上"诊断归因→playbook 假设→探针门禁"的耦合、N3 部署级可复现/可审计评测协议；**不写成"新算法/新网络/首创"**。禁语与改写清单见 §9.3。

### 2.2 学术侧：开放式自改进的五种范式与它们的风险

| 范式 | 代表作 | 做法 | 风险/边界 |
|---|---|---|---|
| 演化式代码搜索 | AlphaEvolve（arXiv:2506.13131）；DGM（arXiv:2505.22954，2025-05） | LLM 生成/改写程序，用可评分评估器选择；DGM 让 agent 改自身代码并归档 | 需要可机读评分；DGM 自述安全风险；**无预算硬门、无版本回滚语义** |
| 参数级自编辑 | SEAL（arXiv:2506.10943，2025）；SICA（arXiv:2504.15228，2025） | 模型生成自己的微调数据/更新（LoRA），或 agent 改自身 scaffold | 自编辑可能强化先验而非扩展能力（第三方分析）；遗忘/污染不可逆 |
| 零数据自博弈 | Absolute Zero（arXiv:2505.03335，NeurIPS 2025）；R-Zero（arXiv:2508.05004） | 自出题+自解、Challenger/Solver 共进化 | 依赖可验证答案；课程塌缩风险 |
| 上下文/记忆自进化 | Agentic Context Engineering（arXiv:2510.04618）、GEPA（arXiv:2507.19457）、ReasoningBank（arXiv:2509.25140）、A-MEM（arXiv:2502.12110） | 进化 prompt/上下文/记忆而非权重 | 记忆污染与错误累积；难审计 |
| 开放式自指 agent | Gödel Agent（arXiv:2410.04444，ACL 2025）、STOP（2023，窗口外） | 自指修改自身逻辑/优化器 | 工程可控性差；离工业合规远 |
| 理论与治理 | Self-Improvement Problem（arXiv:2610.21646）；Gated 动力学（arXiv:2610.03243）；Bilevel Autoresearch（arXiv:2603.23420）；VaG（arXiv:2608.05810）；自进化 agent 综述（arXiv:2507.21046；Cluster Computing 2026 综述 doi:10.1007/s10586-026-06537-4） | 给出"何时/如何进化"的框架与门禁/评估器分离的定理 | **这是 2026 年最直接的新颖性压力来源**（见 §9.2/§9.3） |

**对我们的启示**：开放式自改进的共同前提是"存在可靠评估器"。工业无标签流恰恰没有；我们因此把"评估器"变成**预算内探针标签构造的临时验证器**，并用门禁与回滚约束——这不是"又一个自进化 agent"，而是**在无验证器约束下把自进化做成可运营系统**。

## 9. 与本项目的关系：新颖性、必引文献与口径红线

### 9.1 我们的三条可主张贡献（按文献校准后的写法）

**N1 · 双层受控 RSI 的系统闭环**
- 写法：在工业无标签漂移流上，把 RSI 限制在**有界动作空间（9 个 playbook 白名单）+ 预算硬门（算力/标注/token 逐项记账）+ 探针证据门禁 + 版本仓库回滚 + sha256 哈希链审计 + kill-switch**；模型层只做 playbook 版本滚动，策略层只做 bandit 数值先验更新（两级更新频率不同、可分别回滚）。
- 文献依据：开放式自改进（DGM/SEAL/Absolute Zero/R-Zero/SICA/AlphaEvolve）无预算/无回滚；AI Control 评估外部对手而非自改进系统自身；bounded self-improvement（2610.21646）证明"有界评估+有限提案预算"是可恢复保证的 regime。
- **补充（配套研究 J1，未投稿）**：J1 把"残差由判据自身定义"的自指回路建模为阈值–仿射映射类，证明其可含马蹄与正熵（精确熵 log(2+√3)）、乘子 −32 的周期三（Sharkovsky/Li–Yorke），一般情形不可判定（Koiran/停机归约），且**没有任何单阈值监控能判定参数是否处于混沌区**——即"无外来正确性信道时自改进不可认证"。这解释了为什么我们的设计必须把外部信道显式化（Anchor 标注 / Probe 体检 / 平台隐藏评测隔离），并把 NOOP 与回滚作为一等动作。
- 不能声称：首创受控 RSI、R1–R3 之外的通用安全保证、代码级/权重级递归自改。

**N2 · 无标签漂移流上的"诊断→假设→探针门禁"耦合**
- 写法：把漂移监测输出做**诊断归因**，映射成 9 个可执行 playbook 假设，再用少量**同批留出标签**实测增益、过门禁后才花大预算；NOOP 是合法动作。
- 文献依据：TTA/CTTA 易受标签延迟与伪标签误差影响（2610.12232、2607.08164）；漂移综述停在检测/解释（Hinder 2024、控制与决策 2025）；AutoML/MLE agent 依赖可验证标签（AIDE/MLE-STAR/RE-Bench）。
- 不能声称：首个"检测→动作"系统；必须用消融（A2 关闭诊断 → +0.00）证明诊断-假设映射的贡献。

**N3 · 部署级可复现、可审计的工业自进化评测协议**
- 写法：`run_id + 配置快照 + 实验 SQLite 镜像 + SwanLab 兼容 + 审计哈希链 + 七场景可控漂移基准 + A1–A7 验收（含"不低于静态基线"）+ 负向安全测试 + 一键复现脚本`。
- 文献依据：MLOps/AgentOps/可复现性清单都停在论文级或运行级，**没有把"每次自改进更新"作为一等公民记录**。
- 不能声称：算法创新；应定位为"治理/评测协议 + 开源实现"。
