# 智训引擎 · 项目一页纸

> 第二届北京市大学生"人工智能+"创新大赛 · 赛题「智训引擎——工业制造场景下的模型训练与超参数优化」
> 一句话：**在无标签、持续漂移的工业数据流上，让模型自己发现失准、自己归因、自己设计实验、自己评估上线、自己回滚——每一步都记账、可审计、可复现。**
> 结果状态：**已冻结（3 seeds 7/17/27）**，数字见 `results/SUMMARY.json`、`results/acceptance.json`，可 `python scripts/summary_numbers.py` 复核。

---

## 1 问题（评委关心的是"为什么难"）

工业模型部署后不会一劳永逸：轴承磨损、刀具钝化、传感器老化、工况切换、新故障出现、维修复位，
都会让数据分布持续漂移。赛题同时压了四道约束：

| 约束 | 难在哪 |
|---|---|
| 部署流**无标签** | 不能靠"拿新数据重训一遍"解决，必须先判断"要不要动、动哪里" |
| **预算受限** | 算力、标注配额、Token 都进客观分分母，错误更新比不更新更糟（NOOP 是合法动作） |
| **五阶段闭环自动跑** | 监测→诊断→实验→上线→回滚是一条状态机，不是五个脚本 |
| **安全可控 + 全程留痕** | 受控 RSI、无网络、可回滚、每个数字可反查到 run_id |

## 2 方法（我们做了什么）

### 2.1 五阶段闭环（`src/loop.py`）

```
无标签窗口 → 监测(MMD/KS/熵-边际/Page-Hinkley/novelty/探针准确率)
          → 诊断归因(8 类漂移 + 仿射可恢复性实测)
          → 实验优化(9 个 playbook 成本阶梯，bandit 规划 + 预算硬约束)
          → 评估上线(门禁 4 判：增益/类召回/校准/成本)
          → 回滚(watchdog 连续退化自动回退) —— 全部写入 Decision + sha256 哈希链审计
```

### 2.2 双层受控 RSI（本方案的路线选择）

| 层 | 自改进内容 | 边界 |
|---|---|---|
| 模型层 | 9 个 playbook 产生的**不可变模型版本**在 registry 中滚动 | lineage 完整、随时可回滚 |
| 策略层 | bandit 把"诊断类型→动作→实测增益/成本"写回策略表 | **只改数值先验**，不改代码/门禁/预算；可 diff、可审计 |

**为什么不是纯微调 / 纯 Agent**：纯微调便宜但笨（每类漂移都重训，传感器老化这种零标签可解的也烧标注）；
纯 LLM Harness 聪明但贵且不稳定（token 直接进成本分母，高频决策不可复现）。
我们把贵的 LLM 移到低频开放式决策，高频数值决策用确定性策略 + 在线 bandit（0 token）。
Harness 完整存在：**12 个工具 + 6 个技能 + 确定性/LLM 双驱动**；LLM 驱动已用 mock provider 跑通闭环（S7 +7.84pt、108,612 mock token 估算）。

### 2.3 核心创新：诊断可测 + 最小充分动作

`NOOP / RECALIBRATE_AFFINE(0 标签) / PRIOR_CORRECTION(0 标签) / LAST_LAYER_FT → FULL_FINETUNE_REPLAY → RETRAIN_MIXED → NOVEL_CLASS_EXTEND → SHADOW_ONLY / ROLLBACK`。
关键创新是**仿射可恢复性实测**：用预算内探针标签实测"目标域统计量对齐后准确率回升多少"，
回升显著才判 `covariate_affine`（零标签校准），否则升级为带标签微调——把诊断从定性做成定量。

## 3 结果（全部为仓库实测，`results/SUMMARY.json`）

**主实验（S7 综合漂移，3 seeds）**

| 方法 | 流式 F1 | 增益 | 标注 | 算力(units) | 等效成本 | 单位增益成本 |
|---|---|---|---|---|---|---|
| B0 静态基线 | 0.7014 | — | 0 | 0 | 0 | — |
| B1 周期重训 | 0.7973 | +9.6pt | 1200 | 926 | — | 99.12 |
| B2 Oracle 上界 | 0.9118 | +21.1pt | 7200 | 552 | — | 33.09 |
| **Ours（自进化）** | **0.8000** | **+9.86pt** | **196** | **0.0** | **3.92** | **0.40** |

- 逐 seed 增益 **+8.77 / +9.71 / +11.11**；**0 适应算力 + 约 196 条标注即超过周期重训**（1200 标注/926 units）；
- 验证据 `results/acceptance.json`：**A1–A7 全 PASS**；"不低于静态基线" A2 ✅（0.8014 vs 0.7138，+8.77pt）；
- 可复现：同配置重跑逐窗口曲线与决策序列**完全一致**（A7）。

**七场景（3 seeds 均值，相对静态基线平均 +5.01pt）**

| 场景 | S1 磨损 | S2 老化 | S3 工况 | S4 新类 | S5 修复 | S6 先验 | S7 综合 |
|---|---|---|---|---|---|---|---|
| 静态 F1 | 0.8209 | 0.9501 | 0.6443 | 0.7816 | 0.9451 | 0.9805 | 0.7014 |
| 自进化 F1 | 0.8726 | 0.9599 | **0.8344** | 0.7816 | 0.9456 | 0.9805 | **0.8000** |
| 增益(pt) | +5.17 | +0.98 | **+19.00** | +0.00 | +0.06 | +0.00 | **+9.86** |

> S6 是良性负对照（只改类别先验，目标是不乱花钱）；S4 受"新类锚定标签"预算限制；S5 靠看门狗回滚保稳。

**消融（S7，3 seeds）**：**A2 关诊断 → +0.00**、**A7 关零标签 TTA → −0.56**，证明"诊断 + 最小充分动作"是主收益来源；
A1/A3–A6 与主实验相同，因为预算内只发生 1 次 TTA 更新，它们的作用是**安全**（门禁/回滚/审计），`docs/10 §4` 如实说明。

**预算扫描（S3/S7）**：60 条 → S7 +6.94、S3 −0.59；120 条 → S7 +10.34、S3 +19.40；220 条 → S7 +9.86、S3 +19.00。
**决策质量**：覆盖率 68.9%、兑现率 12.2%、门禁拒绝"增益不足"候选 70.3%（`results/tables/decision_analysis.json`）。
**真实数据闭环**：UCI AI4I 2020 同套系统只换 `benchmark.adapter` → 0.4964 → **0.5527（+5.63pt）**，3 seeds。

## 4 价值（为什么值得给分）

1. **工业价值**：漂移分型 + 成本阶梯直接对应工厂的真实选择——"传感器老化别重训，换个校准就行"；
   实测 S7 用 196 条标注/0 算力达到周期重训 1200 条标注/926 units 的水平，单位增益成本 1/248；
2. **评分对齐**：优化目标就是赛题客观分口径（单位增益成本），所有成本逐窗口记账，给三组权重敏感性 + Pareto；
3. **可迁移**：`DatasetAdapter` 隔离数据格式，AI4I 已实证"换 adapter 即闭环"；LLM provider 一条配置切 PyTRi0；
4. **可验证**：一条命令跑完闭环，`scripts/acceptance.py --repro` 一键 A1–A7 全 PASS；
   每个决策可反查 `run_id` → `config_used.json` → `experiments/runs/<run_id>/`，审计链 `audit-verify` 校验；
   全量 5973 条实验记录可查询/导出/汇编。

## 5 边界（主动说，避免被问倒）

- 校赛**没有官方数据包**：主实验在可控合成漂移基准上，隐藏测试流与标注预算约束在仿真中真实生效（0.34 隔离 + oracle）；
  真实数据用 AI4I 佐证（同套代码闭环 +5.63pt），官方数据接入路径见 `docs/15`；
- 校赛**没有 PyTRi0 额度**：LLM 驱动仅 mock 验证（+7.84pt、108,612 mock token），真实大模型对比留企业赛；
- S4 开集新类 0.00（新类锚定标签预算不足）、S7 中后段预算耗尽后退化 NOOP——**预算边界内的正确保守行为**；
- 小模型（numpy MLP，48 维预提取特征）在本任务足够；原始长序列端到端需换 adapter/模型。
