# 01 · 漂移分诊（Drift Triage）

> 目标：在每个窗口用**最少的成本**回答一个问题——"这波漂移要不要管？"
> 工具：`inspect_drift`（只读）→ 必要时 `diagnose`（可能消耗少量标注）。
> 依据：`monitor` 配置（mmd_threshold=0.35、ks_alpha=0.001、proxy_drop_threshold=0.055、
> warmup_chunks=4、novelty_threshold=0.6）。

## 1. 报警分级

| 级别 | 判据（满足任一） | 处置 |
|---|---|---|
| 无漂移 | `drift_detected=false`，或 `max_severity ≤ 0.05` | **NOOP**，只记录指标 |
| 弱漂移 | `0.05 < max_severity < 0.15` | NOOP + 连续 2 窗口观察（`min_gap=1` 内不重复干预） |
| 中等漂移 | `0.15 ≤ max_severity < 0.55`（`severity_high` 以下） | 先诊断，再做**低成本** playbook（仿射/先验/线性头） |
| 强漂移 | `max_severity ≥ 0.55` | 诊断后可直接评估 `FULL_FINETUNE_REPLAY` / `RETRAIN_MIXED` / `NOVEL_CLASS_EXTEND`（仍受预算&门禁约束） |

补充分诊信号（与严重度同权，取更高等级）：

- `mmd` 超阈值 0.35：协变量/工况漂移信号，倾向 `covariate_affine` / `condition_switch`；
- `ks_topk` 在少数特征显著（α=0.001）且 `affected_groups` 集中：传感器通道问题→仿射；
- `page_hinkley_proxy` 触发（代理指标掉 >0.055）：性能真实下滑，必须诊断；
- `novelty` > 0.6 或新类探针命中：优先怀疑 `novel_class`，不要用仿射硬拗；
- `probe_error` 上升但 MMD 平稳：可能是概念漂移/标签先验漂移。

## 2. 三个必查前提（缺一不可贸然行动）

1. **是否 warmup 期**：`t < warmup_chunks(4)` 的统计量不可靠，只记录不干预；
2. **是否连续触发**：同一 `phase` 内上一个窗口刚处理过、且 `min_gap=1` 未过，
   除非严重度继续上升 ≥ 0.2，否则等待；
3. **是否有可回滚版本**：没有稳定 `champion` 时禁止高风险动作。

## 3. 反例（常见误判）

- ❌ **单窗口尖峰就重训**：噪声膨胀 `noise_inflate` 场景单窗口 MMD 会超阈值，但下一窗口
  回落；正确做法是 NOOP + 观察。反例判据：`mmd` 超阈值但 `proxy_entropy`/`proxy_margin`
  与参考窗口差异 <5%。
- ❌ **把"修好了"当漂移**：`repair` 阶段流分布回归基线，MMD 会报警（相对当前阶段参考窗口），
  此时最该做的是 `ROLLBACK` 到基线版本或 NOOP，而不是继续训练。
- ❌ **把新故障当噪声**：新类出现时熵/边际异常但 MMD 未必极高，只看 MMD 会漏检；
  必须结合 `novelty` 与诊断置信度，必要时花少量标签 `request_labels` 验证。
- ❌ **每日/每窗口都诊断**：诊断本身可能消耗标注预算，弱漂移先等待确认。

## 4. 分诊输出（写进轨迹，供审计）

```json
{"t": 12, "phase": 2, "level": "medium", "drift_detected": true,
 "max_severity": 0.31, "signals": ["ks_topk", "probe_error"],
 "action": "diagnose", "reason": "KS 在 3 个振动通道显著且探针误差上升 6pt，需归因"}
```

## 5. 禁忌

- 禁止绕过 `inspect_drift` 直接跑实验（无证据实验 = 无法归因的消耗）；
- 禁止在 warmup 期消耗任何标注预算；
- 禁止把 `confidence < 0.40` 的诊断当成确定结论去升级高风险 playbook。
