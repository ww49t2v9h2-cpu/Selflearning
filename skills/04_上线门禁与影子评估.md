# 04 · 上线门禁与影子评估（Deploy Gate & Shadow Eval）

> 目标：只有**可复现、有增益、不塌陷、成本可控**的候选才允许替换 champion。
> 工具：`evaluate_candidate`（默认门禁口径）→ `deploy`（写动作）→ `shadow_eval`（只评估不上线）。
> 依据：`gates`（min_gain_points=0.01、min_probe_gain=0.005、max_recall_drop=0.12、
> max_cost_per_update=40.0、shadow_required=False、rollback_window=3、
> rollback_drop_points=0.03）。

## 1. 门禁逐项判据（全部通过才 `promote`）

| 项 | 阈值 | 说明 | 不通过的处置 |
|---|---|---|---|
| probe 增益 | `Δprobe_macro_f1 ≥ min_probe_gain(0.005)` | 候选相对 champion 的探针 macro-F1 提升 | `reject`，候选归档 |
| 召回不塌陷 | `class_recall_min ≥ champion_min - max_recall_drop(0.12)` | 防"平均涨、小类崩" | `reject` |
| 校准不恶化 | ECE 增幅 ≤ 0.02（若引擎提供） | 防过度自信 | `shadow` 或 `reject` |
| 成本可控 | `cost_actual.compute_units ≤ max_cost_per_update(40)` | 单次更新算力上限 | `reject` |
| 可复现 | 候选 artifact 可加载、seed/params 已记录 | 审计硬要求 | 视为实验失败 |
| 风险审批 | high-risk playbook 记录 escalation | `NOVEL_CLASS_EXTEND`/`RETRAIN_MIXED` | 记录 escalation 后放行或人工 |
| 回滚保障 | 存在上一稳定版本 | 上线前检查 | 先 `SHADOW_ONLY` |

> 额外口径：`Δprobe_macro_f1` 用同一批探针标签、同一窗口计算；**禁止**用训练集/隐藏测试
> 指标冒充探针。低于 1 个百分点的波动（<0.005 且跨窗口标准差 >0.5pt）视为噪声。

## 2. 决策三类

- `promote`：全部门禁通过 → 调 `deploy(version)` 上线，记录 `Decision.outcome`；
- `shadow`：部分指标存疑（如校准、稳定性）→ `SHADOW_ONLY`/`shadow_eval`，
  下一个窗口再评估；本窗口 champion 不变；
- `reject`：增益不足/成本超限/复现失败 → 归档候选，记录 reason，不重试同一配置。

## 3. 影子评估用法

- 候选刚训练完、或处于低置信度诊断：先 `shadow_eval` 看
  `pred_stability`（与 champion 预测一致率）与熵差，**不消耗标签**；
- 若一致率 < 0.6 且 probe 未明显提升 → 大概率是"换了一种错法"，直接 reject；
- 若一致率 0.6~0.85 且 probe 提升 ≥ 0.5pt → 可以进正式评估；
- 影子评估结果写入 `state["shadow_results"][exp_id]`，作为下一窗口复评证据。

## 4. 反例

- ❌ **只看 accuracy 不看 class_recall_min**：小样本类别塌陷在均值上被掩盖，
  上线后在 hidden test 上暴露（`max_recall_drop` 就是为此设置）。
- ❌ **probe 波动 0.3pt 就上线**：探针只有 6 条/次，标准误很大；低于
  `min_probe_gain=0.005` 的变化不构成证据。
- ❌ **高风险 playbook 跳门禁**：`NOVEL_CLASS_EXTEND` 必须看新类 recall 与旧类遗忘
  （旧类召回下降 > 0.12 即拒绝）。
- ❌ **部署后不做上线观察**：deploy 之后每个窗口都要喂 `Watchdog`，
  `rollback_window=3` 内掉点 > 0.03 必须回滚（见 05）。
- ❌ **LLM 自批高危动作**：模型不能自己批准 `high_risk` 动作，只能记录 escalation；
  批准权在 `ToolContext.approvals`（loop/人类注入）。

## 5. 门禁结果记录格式

```json
{"criteria": {
   "probe_gain":      {"value": 0.021, "threshold": 0.005, "pass": true},
   "class_recall_min":{"value": 0.71,  "threshold": 0.65,  "pass": true},
   "cost":            {"value": 18.4,  "threshold": 40.0,  "pass": true}},
 "passed": true, "decision": "promote", "reason": "probe +2.1pt，召回未塌陷，成本 18.4"}
```
