# 智训引擎 · 工业模型自进化系统（Self-Evolving Industrial Model）

> 第二届北京市大学生"人工智能+"创新大赛 · 赛题「智训引擎——工业制造场景下的模型训练与超参数优化」
> 命题企业：软通计算机有限公司、华为技术有限公司

**一句话**：在无标签、持续漂移的工业数据流上，让模型**自己发现失准、自己归因、自己设计实验、
自己评估上线、自己回滚**；每一分算力/标注/Token 都记账，每一步决策都可审计可复现。

```
漂移监测 → 诊断归因 → 实验优化 → 评估上线 → 回滚
     ↑                                        │
     └──── 策略层自改进（bandit 策略表）◀──────┘
```

## 快速开始

```bash
PY=python3
$PY scripts/smoke.py          # 数据+模型+适应原语 冒烟（约 3 秒）
$PY -m unittest discover -s tests -v
```

## 设计原则

1. **预算意识**：目标是单位增益成本，不是单纯精度；NOOP 也是合法动作。
2. **证据驱动**：每次更新必须先用少量探针标签实测增益，再决定是否花大预算。
3. **受控自改进**：策略层只改数值先验；动作白名单 + 预算硬门 + 高风险升级 + kill-switch + 哈希链审计。
4. **可复现**：显式 seed、配置快照、每次 run 一条 `run_id`，数字可反查到代码与记录。
5. **可替换**：官方数据包通过 `DatasetAdapter` 接入；LLM 通过 provider 接入（PyTRi0）。

## 安全边界

- 运行期不访问网络、不执行任意代码、不写入白名单之外的路径；
- `STOP` 文件出现即中止一切更新（保留预测与审计）；
- 审计日志为 sha256 哈希链，`python -m src.cli audit-verify` 可校验完整性。
